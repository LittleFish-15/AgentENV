# 统一入口停止与已有 Git 仓库构建

用户要求先停止正在执行的下载/构建，并改用 `/home/jwk` 下已经 git clone 的 AgentENV，检出正确提交后继续编译。

原统一入口只有执行锁和任务队列，无法在旧任务持锁时领取取消任务；修改队列也不会终止已运行进程。因此本次一次性升级已知 root-start.sh 包装层，先执行固定摘要的 stop007 分发器，再进入原 entry.py。原 entry.py 文件、摘要、机器身份校验、结果去重和未确认状态保护不变。升级前核对原包装层字节并保留备份，不覆盖未知入口。

stop007 的权限来自用户明确要求停止当前命令。它核对私有计划、目标 build006 的任务描述、源码摘要、机器/启动身份，通过实际 task.py 路径找到唯一 root 管理进程及其父入口监控进程，只取消该进程树；信号使用 pidfd 防止 PID 复用。包事务正在进行时停止取消操作，不批量 pkill。确认任务进程不存在、执行锁已释放后，保留原状态副本和全部旧文件，以明确的控制器取消代码125记录非成功终态，并单独上传007回执。
